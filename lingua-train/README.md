# 🚆 قطار اللغات

تطبيق ويب لتعلّم تكوين الجمل (مستوى المبتدئ) في **٦ لغات**: الإنجليزية، الإسبانية، الفرنسية، الإيطالية، البرتغالية البرازيلية، الألمانية.
افتح `index.html` في المتصفح، ولا يحتاج أي تثبيت.

## الفكرة

- **جملة واحدة ← ٣٠ صيغة:** فاعل + فعل + مفعول به + تكملة زمان تناسب الزمن (أمس / كل يوم / غداً).
  تتحول الجملة نفسها إلى ١٠ صيغ في كل زمن من الأزمنة الثلاثة (الماضي ثم الحاضر ثم المستقبل):
  مثبت ← منفي ← سؤال نعم/لا مع الجواب ← مَن (الفاعل) ← ماذا (المفعول به) ← متى ← أين ← لماذا ← كيف ← لِمَن (الملكية).
- **لوحة ثابتة:** كل صيغة تبقى أمام المتعلم، والصيغة التالية تظهر تحتها. الأعمدة هي الأزمنة، والصفوف هي الصيغ.
  على الجوال يظهر عمود واحد، وينتقل تلقائياً للزمن الذي يُعرض الآن.
- **تسارع القطار:** كل صيغة تُعرض كلمة كلمة مع نطق كل كلمة، ثم تتكرر الجملة كاملة بسرعة أعلى في كل مرة
  (عربات القطار = عدد التكرار، وعدّاد السرعة يوضح السرعة الحالية). وبعد نهاية اللوحة: «جولة إكسبريس» لكل الصيغ بسرعة.
- **ألوان أجزاء الجملة:** الفاعل أسود، الفعل المساعد أخضر، الفعل الرئيسي أحمر، المفعول به أزرق، أداة النفي رمادي،
  أداة الاستفهام وردي، الزمان بنفسجي، المكان برتقالي، السبب أخضر مزرق، الكيفية بنّي، المالك أزرق سماوي.
- **الضمائر بالتدريج:** كل خط (وحدة) فيه ١٠ جمل. أول جولة كلها بضمير «أنا»، ثم نعود للجملة الأولى بضمير «أنتَ»،
  ثم «هو/هي»، ثم «نحن»، ثم «هم». في الأسئلة يتحول الضمير منطقياً (I → Did **you**…? → Yes, **I** did).
- **خيارات العرض:** تسارع (هادئ / متوسط / سريع) أو سرعة ثابتة، عدد التكرار من ١ إلى ٥، عرض تلقائي أو يدوي،
  تشغيل/إيقاف النطق، اختيار الصوت لكل لغة، والضغط على أي صيغة يشغّلها فوراً.
- **تمارين الإتقان (١٠ أسئلة بعد كل محطة):** 🧩 ترتيب الكلمات، 🎯 اختيار الصيغة المطلوبة، 🎧 استمع واختر،
  🔦 صيد الأدوار (اضغط على الفعل الرئيسي…)، ⚡ العرض الخاطف (في أي زمن؟)، ✏️ أكمل الفراغ.
- **التحفيز:** نقاط خبرة، سلسلة أيام 🔥، نجوم لكل محطة، خريطة خطوط قطار ملوّنة، وبنك كلمات مع النطق.

## المحتوى

- **٨ خطوط × ١٠ جمل = ٨٠ جملة**، و٦١ فعلاً، وأماكن وأسباب وكيفيات وأزمنة وأفراد عائلة تُستخدم في أجوبة الأسئلة.
- **٢٤٠٠ صيغة لكل لغة** (٨٠ جملة × ٣٠ صيغة) تتكرر مع ٦ ضمائر في ٥ جولات.
- عدد الكلمات والتصريفات المختلفة التي يراها المتعلم: الإسبانية ٧٨٥، الإيطالية ٩١٩، الفرنسية ٦٣٢، البرتغالية ٦٢٧، الألمانية ٤٦٢،
  الإنجليزية ٣٤٢ (الإنجليزية أقل لأن أفعالها لا تتصرّف كثيراً).
- الأزمنة: الإنجليزية (Past Simple / Present Simple / will)، الإسبانية (Pretérito / Presente / ir a)،
  الفرنسية (Passé composé / Présent / Futur proche)، الإيطالية (Passato prossimo / Presente / Futuro semplice)،
  البرتغالية (Pretérito perfeito / Presente / ir + infinitivo)، الألمانية (Perfekt / Präsens / Futur I).
- الإسبانية بالمفردات اللاتينية (ustedes، carro، computadora)، والبرتغالية برازيلية (você، celular).

## الملفات

| الملف | المحتوى |
|---|---|
| `data.js` | اللغات، الضمائر، الأفعال وتصريفاتها الشاذة، الأماكن والأسباب…، والوحدات والجمل |
| `grammar.js` | محرّك القواعد: يصرّف الأفعال ويبني الصيغ الثلاثين لكل لغة ويعطي كل كلمة دورها (لونها) |
| `app.js` | الواجهة: الخريطة، لوحة الصيغ والتشغيل المتسارع، التمارين، بنك الكلمات، الإعدادات |
| `index.html` | الهيكل والتصميم |

## إضافة محتوى

- **جملة جديدة:** أضف سطراً داخل `s` في إحدى الوحدات في `LT.UNITS` (الفعل، أيقونة، المعنى بالعربية، المفعول به بكل لغة، ثم أرقام المكان والسبب والكيفية والمالك).
- **فعل جديد:** أضفه في `LT.VERBS`. الأفعال القياسية تكفيها صيغة المصدر، والشاذة تُكتب تصريفاتها.
- **لغة جديدة:** أضفها في `LT.LANGS` و`LT.PRON` و`LT.TIME` وأعمدة الجداول، ثم أضف قسماً لها في `build()` داخل `grammar.js`.

النطق يستخدم أصوات الجهاز (Web Speech API). إن لم يوجد صوت للغة، ثبّته من إعدادات الجهاز (مثلاً: الإعدادات ← اللغة ← تحويل النص إلى كلام).
