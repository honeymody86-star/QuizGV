# محرك الدروس المتميزة

**من إعداد: أ. محمد عطية الزهراني — مدرسة عثمان بن عفان الثانوية**

يلتقط المعلم صورة صفحة الدرس، فيُخرج المحرك درسًا كاملًا مصممًا لتحقيق الدرجة الكاملة في فقرات **بطاقة الملاحظة الصفية** السبع عشرة (هيئة تقويم التعليم والتدريب 2024–2025)، وفي معايير **خطة العمل الإجرائية للمعلم**، مع كل ما تحتاجه الحصة جاهزًا للطباعة والعرض.

## طريقة التشغيل
- **عبر الإنترنت:** بعد تفعيل GitHub Pages للمستودع يصبح الرابط:
  `https://honeymody86-star.github.io/QuizGV/lesson-engine/`
- **بدون استضافة:** افتح `index.html` مباشرة في المتصفح (Chrome أو Edge). في هذه الحالة يعمل الكويز من جوالات الطلاب عبر رابط الاستضافة أعلاه.

## ثلاث طرق للتوليد (يخرج الدرس في كل الأحوال)
| الطريقة | ماذا يلزمك | الجودة |
|---|---|---|
| 🔗 **مجاني بدون مفتاح** (موصى به) | حساب مجاني في Gemini أو ChatGPT أو Claude أو Copilot أو DeepSeek | ممتازة |
| ⚡ **تلقائي بمفتاح API** | مفتاح **Gemini مجاني** من Google AI Studio، أو OpenRouter المجاني، أو مفتاح OpenAI/Claude | ممتازة، بضغطة واحدة |
| 🛟 **المحرك الذاتي** | لا شيء: يقرأ نص الصورة (OCR) ويبني الدرس بقوالب جاهزة | جيدة، وراجع المحتوى العلمي |

إذا فشل الاتصال بالذكاء الاصطناعي ينتقل المحرك تلقائيًا إلى المحرك الذاتي، فلا تتوقف الحصة.

## مخرجات كل درس
1. **خطة الدرس:** نواتج التعلم، والقيم والهوية الوطنية ورؤية 2030، وميثاق التعامل، والتوزيع الزمني دقيقة بدقيقة، والإستراتيجيات (قاعدة 3+3)، والمصادر مع روابط البحث في يوتيوب وعين، وأسئلة التفكير العليا، والربط بالحياة، والقراءة والكتابة والحساب، والفروق الفردية، وأدوات التقويم الثلاثة، وبنك عبارات التغذية الراجعة الوصفية.
2. **ورقة العمل المتمايزة:** ثلاثة مستويات (انطلق / حلّق / أبدع)، وعليها رمز QR للكويز، ومهمة حسابية، وتقويم الأقران، وتقويم ذاتي، ونسخة بخط مكبر.
3. **البطاقات:** بطاقات الخروج، وبطاقات الاستجابة المتزامنة A/B/C/D، وبطاقات المفاهيم.
4. **العرض التفاعلي:** شرائح بمؤقت مرئي لكل نشاط، واختيار عشوائي للطلاب، وزمن تفكير صامت، ونرد، ولوحة نقاط، ونتائج الكويز المباشرة، وصور توضيحية مجانية، وأوامر صوتية. ويُصدَّر العرض إلى PowerPoint.
5. **أدوات الحصة:** أعواد المثلجات الرقمية بلا تكرار مع سجل المشاركة، وتكوين المجموعات بأدوار، ولوحة النقاط، والكويز المباشر، والتحكم في اللابتوب من الجوال.
6. **أدوات خارجية:** ملف Kahoot وWayground (Quizizz)، ونص Wordwall، وكود ينشئ اختبار نماذج Google، ومصدر NotebookLM مع موجّه البودكاست والفيديو، وموجّهات Gamma وCanva وGemini Canvas والصور، وموجّه يجعل Claude ينفّذ الخطوات على جهازك.
7. **التقرير المتكامل:** لكل فقرة من الفقرات السبع عشرة: المشاهدات الدالة، وما يقابلها في الدرس، وما يفعله المعلم عمليًا، والدرجة المتوقعة. ثم مطابقة معايير خطة العمل الإجرائية.
8. **دليل المعلم:** قائمة ما قبل الحصة، وسيناريو الحصة، وعبارات جاهزة، وتكتيكات حصة التقويم الخارجي.

كل المستندات قابلة للتعديل بالنقر عليها قبل الطباعة، وتُصدَّر إلى PDF وWord.

## الخصوصية
مفاتيح API وأسماء الطلاب والدروس المحفوظة تبقى في متصفح المعلم فقط. ترسل الصورة إلى مزود الذكاء الاصطناعي الذي يختاره المعلم فقط.

## الملفات
- `index.html`: التطبيق.
- `student.html`: صفحة الكويز للطالب.
- `remote.html`: صفحة التحكم من الجوال.
- `js/criteria.js`: نص بطاقة الملاحظة وخطة العمل والتكتيكات.
- `js/prompt.js`: الموجّه الرئيس وهيكل الدرس.
- `js/report.js`: مطابقة الدرس مع المؤشرات.
- `js/offline.js`: المحرك الذاتي.
- `vendor/`: مكتبات مفتوحة المصدر مضمّنة ليعمل المحرك دون الاعتماد على شبكات التوزيع (CDN).
