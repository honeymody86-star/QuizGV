# Passo a Passo — تعلّم اللغات بتركيب الجمل عبر الأزمنة

تطبيق ويب يمشي معك فيه معلّم صوتي («لوكا») خطوة بخطوة. يبني الجملة أمامك كلمة كلمة **في عدّة أزمنة في نفس الوقت**:
يظهر الفاعل في الأزمنة الثلاثة ويثبت، ثم يظهر الفعل بجانبه في الأزمنة الثلاثة، ثم المفعول به. يرافق ذلك صوت المعلّم وشرحه.
بعد كل جملة تكرّر وراءه، ثم يسألك بدون أن ترى الجملة (على طريقة Pimsleur)، وبعد كل جزء اختبار سريع.

اللغة المتاحة الآن: **الإيطالية**. لغة المعلّم: **العربية** أو **الإنجليزية**.

## التشغيل

```bash
cd passo
python3 -m http.server 8080      # ثم افتح http://localhost:8080
```

أو افتح `passo/index.html` مباشرة في المتصفح. وللنشر يكفي رفع المجلد على GitHub Pages أو Netlify أو أي استضافة ملفات ثابتة.

> أفضل تجربة على **Chrome** أو **Edge**، لأنهما يوفّران أصواتًا جيدة للعربية والإيطالية، ويدعمان التعرّف على الصوت.
> التعرّف على الصوت (الميكروفون) يحتاج رابط `https` أو `localhost`.

## طريقة الدرس (ما يفعله المعلّم)

1. **مقدمة**: هدف الدرس والأزمنة التي سنقارن بينها.
2. **بناء الجملة**: يظهر كل جزء (الفاعل، الفعل، المفعول به…) في كل الأزمنة معًا ويبقى ثابتًا. نهاية الفعل ملوّنة،
   والفعل المساعد (`ho` / `sono` / `sto`…) مميّز، فترى الفرق بين الأزمنة بعينك.
3. **الشرح**: المعلّم يشرح كل تصريف في أول مرة يظهر فيها (الفعل المساعد، النهاية، الأفعال الشاذة)، وبعد ذلك يكتفي بالنطق.
4. **الجمل كاملة**: ينطق كل سطر بالإيطالية، ثم يقول معناه.
5. **كرّر ورائي**: ينطق ببطء، ثم يأتي دورك (الميكروفون يسمعك ويقيّم نطقك، أو تضغط «قلتها»)، ثم يؤكّد بالنطق الصحيح.
6. **سؤال بدون نظر**: تُغطّى الجملة ويسألك: «كيف تقول…؟».
7. **اختبار سريع** كل جملتين، ثم **مراجعة صوتية** لكل جمل الدرس، ثم **اختبار نهائي** (تركيب الجملة، اختيار الفعل، تحديد الزمن، الاستماع، التحويل بين الأزمنة، النطق).
8. الجمل التي تخطئ فيها تُحفظ في **المراجعة الذكية**.

الدرس يمشي بدون توقف، وفيه أزرار ⏮ ⏯ ⏭ (أو زر المسافة والأسهم في لوحة المفاتيح).

## المنهج

| الوحدة | المستوى | المحتوى |
|---|---|---|
| 0 | A0 | خريطة الأزمنة (الأكثر استعمالًا بالنجوم)، تركيب الجملة، سلّم التراكيب |
| 1 | A1 | الثلاثي البسيط: Passato prossimo • Presente • Futuro — كل الضمائر، أفعال essere، النفي، الأسئلة |
| 2 | A2 | الجمل المركّبة: e • ma • o • quindi |
| 3 | A2 | الثلاثي المستمر (stavo / sto / starò + gerundio)، وImperfetto مقابل Passato prossimo |
| 4 | B1 | الجمل المعقّدة: perché • quando • se • che |
| 5 | B1 | الثلاثي التام: Trapassato • Passato prossimo • Futuro anteriore |
| 6 | B2 | أفعال القدرة والوجوب + المصدر، والشرطي (vorrei / avrei voluto) |
| 7 | C1 | Congiuntivo (اليقين مقابل الرأي)، والجمل المركّبة المعقّدة |

## البنية التقنية

```
passo/
  index.html, css/app.css
  js/
    speech.js    الصوت: نطق لكل لغة + التعرّف على الكلام + توقيت بديل إذا لم يوجد صوت
    stage.js     العرض: شبكة المقارنة بين الأزمنة، خريطة الزمن، سلّم التراكيب
    builder.js   يحوّل الدرس إلى «سيناريو» المعلّم خطوة بخطوة
    player.js    يشغّل السيناريو بلا توقف (إيقاف/تقديم/رجوع) ويدير «دورك»
    quiz.js      ستة أنواع من الأسئلة السريعة
    model.js     يحوّل جمل الدرس إلى صفوف (زمن) وأعمدة (أجزاء الجملة)
    match.js     مقارنة ما قلته بالجملة الصحيحة
    i18n.js      نصوص الواجهة وكلام المعلّم بالعربية والإنجليزية
    app.js       الشاشات، الإعدادات، حفظ التقدّم
  lang/it/
    conjugate.js محرّك تصريف الأفعال الإيطالية (كل الأزمنة + الشواذ)
    lexicon.js   الأزمنة، الضمائر، معاني الأفعال
    course.js    المنهج: الوحدات والدروس والجمل
  tests/         اختبارات المحرّك والمنهج + اختبار متصفّح كامل
```

**إضافة جملة**: يكفي كتابة الفعل في المصدر، والمحرّك يصرّفه في كل الأزمنة:

```js
{ segs: [subj('noi'), verb('cucinare'), obj('la pasta', 'المعكرونة', 'pasta', '🍝')],
  g: { ar: ['طبخنا المعكرونة', 'نطبخُ المعكرونة', 'سنطبخُ المعكرونة'], en: [...] } }
```

**إضافة لغة جديدة** (إسبانية، فرنسية…): مجلد جديد في `lang/` فيه نفس الملفات الثلاثة، ثم تسجيله في `PACKS` داخل `js/app.js`.

## الاختبارات

```bash
npm test          # محرّك التصريف + سلامة كل جمل المنهج + مقارنة النطق
npm run e2e       # يشغّل دروسًا كاملة في متصفّح حقيقي (Playwright)
```

## الخطوات القادمة المقترحة

- **أصوات أعلى جودة**: ربط اختياري بخدمة نطق سحابية (Azure / Google / ElevenLabs) مع تخزين الملفات الصوتية مسبقًا.
- **مراجعة متباعدة (SRS)** بجدولة زمنية بدل القائمة البسيطة الحالية.
- **محادثة حرّة** مع المعلّم في نهاية كل وحدة، باستخدام نموذج لغوي.
- اختيار جنس المتعلّم (andato / andata) وتوسيع المنهج بمزيد من الجمل لكل درس.
- لغات أخرى: الإسبانية والفرنسية والألمانية.
