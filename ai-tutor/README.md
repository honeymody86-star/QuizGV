# 🎓 المعلّم المرئي: محرك شرح بالصوت والرسم المتزامن

تسأل سؤالاً (بالكتابة، أو بصوتك 🎙️، أو بصورة 📷)، فيشرح لك المحرك **بصوت بشري** وفي اللحظة نفسها **يرسم على سبورة** مخططات وأسهماً ورسوماً بيانية ومعادلات وعدّادات متحركة. كل عنصر يظهر لحظة نطق الكلمة المرتبطة به، والترجمة النصية تتلوّن كلمةً كلمة.

## كيف يعمل

```
سؤال الطالب
   │
   ▼
① Claude يكتب "سيناريو درس" بصيغة JSON مقيّدة بمخطط (structured outputs):
   مشاهد ← لكل مشهد: نص الكلام + أوامر رسم، وكل أمر مربوط بعبارة (cue) من الكلام
   │  (بثّ تدريجي: المشهد الأول يبدأ قبل أن يكمل النموذج بقية الدرس)
   ▼
② محرك الصوت يحوّل كلام كل مشهد إلى صوت (ويجهّز المشهد التالي مسبقاً)
   │
   ▼
③ المشغّل يعرف أي حرف يُنطق الآن:
     • ElevenLabs: أزمنة كل حرف ← تزامن دقيق
     • صوت المتصفح: أحداث boundary
     • Azure / OpenAI: تقدير نسبي من مدة الملف
   وعندما يصل النطق إلى cue يرسم العنصر على السبورة
   │
   ▼
④ السبورة (SVG + rough.js) ترسم بأسلوب اليد داخل المتصفح ← تكلفة الرسم صفر
```

**الفكرة الاقتصادية الأهم:** لا نولّد فيديو. النموذج يكتب نصاً صغيراً (حوالي ٣ آلاف توكن)، والمتصفح يحوّله إلى رسوم متحركة. لذلك تكلفة الصورة صفر، والوقت حتى أول كلمة بضع ثوانٍ.

## الملفات

| الملف | الدور |
|---|---|
| `index.html` / `app.js` | الواجهة: سؤال نصي وصوتي وبالصورة، أزرار التحكم، الإعدادات، تقدير تكلفة كل درس |
| `lesson-spec.js` | تعليمات المعلّم (system prompt) ومخطط JSON للدرس، ومشترك بين الواجهة والخادم |
| `llm.js` | استدعاء Claude بالبث ومحلّل يستخرج المشاهد المكتملة أثناء الكتابة |
| `tts.js` | مزوّدو الصوت: المتصفح، Azure، ElevenLabs، OpenAI، الخادم |
| `player.js` | المزامنة بين الصوت والرسم والترجمة النصية |
| `board.js` | السبورة: صناديق، دوائر، أسهم، قوائم، معادلات، أعمدة، دائرة نسبية، عدّاد، إيموجي، تظليل |
| `demo-lesson.js` | درسان جاهزان يعملان مجاناً بلا أي مفتاح |
| `worker/` | خادم وسيط على Cloudflare: يخفي المفاتيح، ويخزّن الدروس والأصوات، ويحدّ الاستخدام اليومي |
| `vendor/` | rough.js و Anthropic SDK محفوظتان محلياً (لا اعتماد على CDN) |

## التشغيل

**تجربة شخصية (بلا خادم):** افتح `ai-tutor/index.html` عبر أي خادم ملفات ثابت أو GitHub Pages، ثم:
1. جرّب «▶ تجربة مجانية» مباشرة، فهي لا تحتاج مفتاحاً.
2. للأسئلة الحرة: افتح ⚙️ وضع مفتاح Claude API، واختر مزوّد الصوت.

> ⚠️ المفاتيح في وضع «مباشرة من المتصفح» تُحفظ في متصفحك. هذا مناسب لك وحدك، لكن **لا تنشر الموقع للعامة بهذه الطريقة**.

**للنشر للعامة (الخادم الوسيط):**
```bash
cd ai-tutor/worker
npm install
npx wrangler kv namespace create CACHE      # ضع المعرّف في wrangler.toml
npx wrangler secret put ANTHROPIC_API_KEY
npx wrangler secret put AZURE_SPEECH_KEY    # أو ELEVENLABS_API_KEY مع TTS_PROVIDER=elevenlabs
npx wrangler deploy
```
بعدها في ⚙️ اختر «عبر خادمي الوسيط» وضع رابط الـ worker، واختر الصوت «عبر الخادم الوسيط».

## 💰 الخيارات والتكاليف

افتراضات «الدرس المتوسط»: ٦ مشاهد، نحو **١٤٠٠ حرف كلام** (قرابة دقيقتين صوت)، ونحو **٣٠٠٠ توكن إخراج** من النموذج، مع كاش لتعليمات النظام.

### ١) عقل المعلّم (كتابة سيناريو الشرح)

| النموذج | السعر لكل مليون توكن (إدخال / إخراج) | تكلفة الدرس تقريباً | لكل ١٠٠٠ درس | ملاحظة |
|---|---|---|---|---|
| Claude Opus 5.5 | $4 / $20 | ~$0.065 | ~$65 | أفضل تخطيط للرسوم وأدق شرح |
| Claude Sonnet 5.5 | $2 / $10 | ~$0.032 | ~$32 | **توازن ممتاز، ونقطة البداية المقترحة** |
| Claude Haiku 5.5 | $0.10 / $0.50 | ~$0.002 | ~$2 | رخيص جداً، وجيد للأسئلة البسيطة والمراجعة |

- **كاش تعليمات النظام** (مفعّل في الكود): قراءة الكاش تكلّف نحو ٥٪ من سعر الإدخال.
- **كاش الدروس في الخادم**: السؤال المتكرر (مثل «الممالك الست» الذي يسأله آلاف الطلاب) يُخدم من التخزين **بتكلفة صفر**. لو كان نصف الأسئلة متكرراً تنخفض الفاتورة إلى النصف.
- **اقتراح عملي:** وجّه الأسئلة القصيرة والسهلة إلى Haiku، والباقي إلى Sonnet، وأبقِ Opus للمسائل الصعبة. هذا التوجيه غير مبرمج حالياً؛ اختيار النموذج من الإعدادات.

### ٢) الصوت (أهم عنصر في الإحساس «البشري»)

| المزوّد | السعر | تكلفة الدرس (١٤٠٠ حرف) | لكل ١٠٠٠ درس | الجودة بالعربية | التزامن |
|---|---|---|---|---|---|
| صوت المتصفح (Web Speech) | مجاني | $0 | $0 | تختلف حسب الجهاز. في **Microsoft Edge** أصوات «Online (Natural)» عصبية ممتازة ومجانية، وفي iPhone صوت «مجيد/ليلى» مقبول | أحداث boundary |
| Piper (استضافة ذاتية) | تكلفة خادم فقط | ~$0 | ~$0 إلى $2 | متوسطة، وأقرب للآلي | تقديري |
| **Azure Neural** (ar-SA-Hamed، Zariyah…) | ~$15 لكل مليون حرف | ~$0.021 | ~$21 | **جيدة جداً وطبيعية، ولهجات سعودية ومصرية وخليجية** | تقديري (أو word boundary عبر SDK) |
| OpenAI gpt-4o-mini-tts | ~1.5 سنت للدقيقة | ~$0.027 | ~$27 | جيدة، ويمكن توجيه النبرة («معلم متحمس») | تقديري |

| ElevenLabs Multilingual v2 | ~$0.10 لكل ١٠٠٠ حرف | ~$0.14 | ~$140 | **الأكثر بشرية وعاطفة** | **دقيق حرفاً بحرف** |

- Azure يعطي مجاناً نصف مليون حرف شهرياً (قرابة ٣٥٠ درساً).
- **كاش الصوت في الخادم** (مفعّل): الجملة نفسها لا تُولَّد مرتين.
- خطط اشتراك ElevenLabs الأعلى تخفض سعر الحرف.

**مثال واقعي:** ١٠٠٠ طالب، كل واحد يسأل ٥ أسئلة يومياً، أي ١٥٠ ألف درس شهرياً، ونصفها متكرر يُخدم من الكاش:
- الباقة الاقتصادية: ٧٥ ألف × $0.053 ≈ **$4,000 شهرياً**
- الباقة الأوفر: ٧٥ ألف × $0.023 ≈ **$1,700 شهرياً**
- اشتراك $5 شهرياً من كل طالب يغطي الأولى بهامش ربح جيد.

> الأسعار تقريبية (نوفمبر ٢٠٢٦). أسعار Claude من وثائق Anthropic، وأسعار الصوت من صفحات تسعير ومقالات مقارنة قد تتغيّر. راجع الصفحات الرسمية قبل اعتماد ميزانية.

## خطوات تطوير مقترحة لاحقاً

1. **توجيه تلقائي للنموذج:** Haiku يصنّف السؤال (سهل أو صعب) ثم يحوّله للنموذج المناسب.
2. **تصدير فيديو** للدرس بـ Remotion أو بتسجيل الشاشة، لنشره على تيك توك.
3. **أسئلة متابعة** («لم أفهم هذه النقطة») تُرسل مع الدرس السابق، مع الكاش.
4. **محادثة صوتية حيّة** يقاطع فيها الطالب المعلم: أغلى (~$0.06 إلى $0.30 للدقيقة) لكنها أكثر تفاعلاً.
5. **مكتبة أشكال للمواد**: خلية، ذرة، محور إحداثيات ورسم دوال، خريطة.
